# Contributing

Focused fixes and new founder workflows are welcome.

1. Put each skill in `plugins/tej-stack/skills/<skill-name>/`.
2. Keep `SKILL.md` concise and move detailed material into `references/`.
3. Add direct, indirect, negative, and boundary cases under `evals/`.
4. Run `python scripts/validate.py`.
5. Open a focused pull request with a short description of the behavior change.

Do not add a skill only to increase the count. It should solve a recurring problem with a distinct trigger and a verifiable outcome.
